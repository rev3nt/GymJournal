# Lift Log v1.3.0

## Русский

### Что нового
- Редактирование сохранённых тренировок: подходы, допы, упражнения, дозапись сетов
- Режим просмотра по умолчанию; правка включается кнопкой «Изменить» / «Готово»
- Переименование тренировки долгим нажатием на название (в режиме правки)
- Тоннаж пересчитывается после правок, дата завершения сохраняется

### Установка
Скачайте `LiftLog.apk` из Assets этого релиза.

---

## English

### What's new
- Edit finished workouts: sets, extras, exercises, and logging more sets
- Read-only by default; tap Edit / Done to enter and leave edit mode
- Rename a workout with a long-press on the title (while editing)
- Tonnage recalculates after edits; finished date is preserved

### Install
Download `LiftLog.apk` from this release’s Assets.
