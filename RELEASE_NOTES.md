# Lift Log v1.2.0

## Русский

### Что нового
- Сценарийный интерактивный гайд: шаблон → тренировка → префилл → статистика (с автоочисткой демо)
- Память веса и повторов при повторном старте шаблона
- Маркер ×2 для упражнений на одну руку/ногу (тоннаж удваивается)
- Допы к подходу (дроп / мио / читинг) с правкой из лога
- Незавершённая тренировка сохраняется сама; черновик UI переживает паузу приложения

### Установка
Скачайте `LiftLog.apk` из Assets этого релиза.

## English

### What's new
- Scenario interactive guide: template → workout → prefill → stats (demo cleanup at the end)
- Weight/reps memory when restarting the same template
- ×2 marker for single-limb exercises (doubles tonnage)
- Extra set legs (drop / myo / cheat) editable from the log
- Unfinished workouts persist; UI draft survives app pause

### Install
Download `LiftLog.apk` from this release’s Assets.
