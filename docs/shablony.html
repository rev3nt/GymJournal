Шаблоны тренировок без аккаунта

Соберите программу упражнений и целевых подходов один раз — дальше только запуск сессии.

Что даёт шаблон

В Lift Log шаблон — это набор упражнений и плановых подходов. Вы не пересобираете список каждый раз в зале: открыли шаблон, пошли по упражнениям, записали факты веса и повторов.

  • Список упражнений под день (push / pull / ноги или свой сплит)
  • Целевое число подходов для ориентира
  • Быстрый старт активной тренировки из шаблона

Чем лучше планов «только в браузере»

Сайты вроде workouter.fit сильны контентом планов, но слабее как журнал подходов. Облачные дневники (GymPad, Iron Mind) требуют аккаунт. Lift Log — нативное Android-приложение: шаблон и лог живут на устройстве.

Для кого

Тем, кто ищет «шаблоны тренировок android» и хочет повторяемый сплит без синхронизации в облако.
