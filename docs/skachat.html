Скачать Lift Log APK

Актуальная сборка публикуется в GitHub Releases. Один клик — страница последнего релиза.

Открыть latest release Репозиторий

Требования

  • Android-устройство
  • Разрешение установки из неизвестных источников (для браузера/файлового менеджера)
  • Свободное место под APK и локальную базу

Как установить

  1. Откройте releases/latest и скачайте файл .apk из активов релиза.
  2. В настройках Android разрешите установку из источника, которым пользуетесь (Chrome, Files и т.п.).
  3. Откройте скачанный APK и подтвердите установку. Запустите Lift Log — аккаунт не нужен.

После установки

Соберите шаблон, проведите тренировку, при смене телефона сделайте JSON-бэкап.
